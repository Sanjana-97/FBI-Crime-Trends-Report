# 🕵️‍♀️ FBI Crime Analysis Report

Welcome to the **Crime Analysis Report**, where numbers speak louder than assumptions.

Crime is not random - it has patterns. This project uses **Power BI** to uncover those patterns from real FBI crime data, helping law enforcement and analysts make smarter, data-driven decisions.

## 💡 Key Takeaways

- **Evening hours (5 PM–8 PM)** are peak for crimes.
- **Theft from Vehicle** is the most reported type.
- **Granville Street** tops the list for crime incidents.
- **Weekends (Saturday & Sunday)** are riskiest.
- Crime sharply dropped from **1998 to 2008**, but there’s a slight rise again post-2010.
